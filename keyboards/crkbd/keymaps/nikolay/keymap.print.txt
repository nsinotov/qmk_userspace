NOTES:
- Caps Lock keys are remapped to Globe key (🌐) on macOS
- Globe key enables macOS shortcuts and special functions
- Multiple keys can function as Globe key (hold) throughout the layout
- The Globe key on NAVIGATION layer is used for keyboard language switching
